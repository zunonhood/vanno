# VANNO

VANNO is an onchain PONS treasury project built on Robinhood Chain and designed for launch through pons v2.

Every VANNO trade applies a fixed 3% creator tax:

- 2% targets PONS acquisition and treasury accumulation.
- 1% targets VANNO market buybacks and permanent removal from circulation.
- 0% is allocated to team operations.

The website explains the treasury mechanism, accounting policy, transparency covenant, risks, launch sequence, and an illustrative tax model without presenting pre-launch values as live data.
